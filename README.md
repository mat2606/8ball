# Régua Sinuca

App Android de código aberto: uma régua flutuante, ajustada à mão, sobre qualquer app. Não lê a tela nem o jogo; só desenha linhas fixas que você move.

## Recursos
- Contorno da mesa com 6 caçapas (calibre os 2 cantos laranja uma vez; fica salvo)
- Linhas finas da bola branca até cada caçapa
- Linha principal ajustável por ângulo, com até 4 rebotes nas tabelas
- Bolha flutuante: ▶ = modo jogar (toques passam para o app de baixo), ✎ = modo ajustar

## Como gerar o APK
1. Suba esta pasta em um repositório no GitHub.
2. Aba **Actions** > **Build APK** > aguarde > baixe o artefato `ReguaSinuca-debug`.
   (Ou abra no Android Studio e rode.)
3. Instale o APK, toque em "Permitir sobreposição", depois em "Iniciar régua".

## Dica de calibração
Posicione os cantos laranja na borda interna das tabelas onde o centro da bola bate, para os rebotes ficarem mais fiéis.
